Your task is to analyze the product image, apply the logic in this

Nano Banana Pro image generation prompt that will yield a professional
"Dimension & Scale Visualization" image — a technically precise,
commercially viable product photo with accurate dimension callouts,
annotation lines, scale references, and typographic labels.

The output must meet the visual and technical standard of top-tier
e-commerce platforms: Amazon, Wayfair, Home Depot, Kohler, IKEA.

Do NOT generate the image. Generate only the structured JSON prompt.

SECTION 1 — FIXED FACTORS  (Universal — Apply to ALL Products)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[F-01] IMAGE QUALITY STANDARD
  • Photorealistic or ultra-high-fidelity 3D render quality
  • Studio-grade product fidelity — no noise, lens distortion, or blur
  • Always specify in prompt: "ultra-sharp, studio-grade commercial
    product photography, 4K resolution, high fidelity"
  • Output aspect ratio: 1:1 (square) for marketplace listings by default;
    use 4:5 for mobile-first; 16:9 for banner/hero only if user specifies

[F-02] PRODUCT INTEGRITY
  • The product must be rendered with exact color accuracy, material
    finish, surface texture, and structural proportions as visible in
    the reference image
  • No creative liberties on the product itself — it must be
    immediately recognizable as the same product
  • Include in core_prompt: "faithful reproduction of product finish,
    true-to-reference surface material, accurate structural proportions"

[F-03] DIMENSION LINE SPECIFICATIONS
  • All lines must be perfectly straight (orthogonal or diagonal — never
    curved, freehand, or perspective-warped)
  • Line weight: Visually consistent throughout; thin (0.5–1pt equivalent)
    for catalog/tech style; medium (1.5–2pt) for editorial style
  • Arrowheads: Bidirectional (both ends) — filled triangle for furniture
    and tools; open chevron (←→) for premium hardware
  • Extension lines: Required at both ends of orthogonal measurements
    (short perpendicular cap lines at line termination points)
  • Lines must originate from the product's physical edge and extend
    cleanly into negative space — they must NEVER cross through the
    product's primary visual surface
  • Leader lines (diagonal, for pointing to specific components):
    Fine dashed style, terminating at the component with a small dot or
    subtle arrowhead

[F-04] TYPOGRAPHY — TWO-TIER SYSTEM (Mandatory)
  • Font family: Clean geometric sans-serif ONLY
    (Inter, Helvetica Neue, DIN, or equivalent — NO serifs, NO script)
  • TIER 1 — Dimension Label (component name):
    - Smaller size, regular/normal weight
    - Title Case (e.g., "Faucet Height", "Total Width", "Spout Reach")
    - Positioned above or left of the value on a separate line
  • TIER 2 — Dimension Value (number + unit):
    - Larger size, bold or semi-bold weight
    - Always includes unit — never a bare number
    - Fractional inches use proper fraction notation (e.g., 7⁵⁄₁₆")
    - Metric in parentheses when dual-unit applies (e.g., 7⁵⁄₁₆" (186 mm))
  • Text must NEVER overlap the product's key visual surface
  • Text alignment: Always parallel or perpendicular to its associated
    dimension line; centered on or adjacent to the line midpoint
  • Text color rule: White text on dark backgrounds;
    Dark gray or black text on white/light backgrounds

[F-05] UNIT CONVENTIONS
  • If user provides dimensions: use EXACT values and units — no rounding
  • US-market products (Bath, Kitchen, Furniture): Imperial primary,
    metric in parentheses → e.g., "21¹³⁄₁₆" (549 mm)"
  • Metric-standard products: metric only → e.g., "180mm", "12cm"
  • Weight: Include unit always → "1kg", "100 LBS"
  • Units must be present on every annotation — no naked numbers

[F-06] COMPOSITION RULES
  • Product frame occupancy: 50–70% of total image area
  • Negative space distribution: annotations exist only in the
    clear space AROUND the product, not on top of it
  • Dimension hierarchy by placement:
    - Outermost edges → Overall H, W, D (critical buyer dimensions)
    - Mid-zone (near product) → Sub-component dimensions
    - Inside product boundary → Internal compartment dimensions only
      (shelves, drawer openings) — use short internal lines
  • No annotation element (text or line) may be clipped by the
    image frame border — all must be fully visible
  • Maintain visual balance: annotations should not cluster on one side

[F-07] BACKGROUND RULES
  • Premium metallic / chrome / brass / gold / polished finish:
    → Dark radial gradient background (deep charcoal #1a1a1a to near-
       black #0d0d0d, subtle warm or cool center glow)
  • Matte black / raw metal / industrial finish:
    → Pure white (#FFFFFF) or very light neutral gray (#F5F5F5)
  • Wood-finish / painted furniture / colorful products:
    → Clean white or very soft warm gray — no competing textures
  • Background must be smooth, distraction-free, no objects, no floor
    texture unless critical for scale context
  • Subtle cast shadow or surface reflection permitted for depth;
    no harsh shadows

[F-08] E-COMMERCE COMPLIANCE
  • Image must visually communicate: "This is a professional product
    specification image from a trusted retailer"
  • All critical buyer dimensions must be present so a customer can
    determine if the product fits their space/need without reading
    a separate spec sheet
  • No brand logos, decorative watermarks, or irrelevant design elements
  • Final image must be suitable for the dedicated "Dimensions" image
    slot in an e-commerce product listing (Amazon, Wayfair, etc.)

SECTION 3 — DIMENSION DATA PROTOCOL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[D-01] IF USER PROVIDES DIMENSION DATA:
  • Use EXACTLY the values, labels, and units provided — do not round,
    assume, or convert without adding a secondary unit
  • Map each value precisely to its anatomical location on the product
  • Render labels in Title Case: "Spout Reach", not "spout reach"
    or "SPOUT REACH"
  • Set "estimated": false for all user-provided values

[D-02] IF USER DOES NOT PROVIDE DIMENSION DATA:
  • Analyze the product from the reference image to determine which
    dimensions are most commercially critical for a buyer's decision
  • Use proportional estimation from visible product cues and known
    industry-standard sizes for that product category
  • If the product has a known manufacturer model visible in the image:
    flag a web search for official specifications in the output
  • Prioritize buyer-critical dimensions first:
    - Furniture → H × W × D first; storage openings second
    - Faucets → Total height, spout reach first; valve diameter second
    - Tools → Blade/cutting length first; body H × W × D second
  • Set "estimated": true for all inferred/estimated values
  • Add "web_search_recommended": true if model confidence is low

NANO BANANA PRO TEXT RENDERING RULES:

RESOLUTION & ASPECT RATIO:

  • Specify explicitly in every core_prompt
